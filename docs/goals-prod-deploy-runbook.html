Deploy Goals lên VPS

Runbook · 27/10/2026 · Repository congvu99/Goals

Dự án hiện là một trang HTML tự chứa CSS và JavaScript: ke-hoach-phan-bo-7-2-trieu.html. Không cần backend, database, .env hoặc npm build. Mã hiện tại không gọi API và không lưu lựa chọn bằng localStorage. Tài liệu đã đối chiếu cấu trúc local; chưa kiểm tra hoặc deploy trên VPS.

1. Môi trường Goals

Repo được xác nhận từ Git remote local. IP và SSH kế thừa tài liệu mẫu; domain Goals là đề xuất chưa xác nhận hoạt động. Thay đồng nhất các giá trị nếu môi trường thực tế khác.

Quy trình yêu cầu Caddy dùng chung bind-mount cả /srv/caddy/conf vào /etc/caddy và import sites/*.caddy. Chỉ chép HTML ứng dụng vào web root, không phục vụ cả repo, .git, docs hay nhật ký.

2. Đẩy code lên GitHub

WINDOWS — PowerShell. Git, main và origin đã có; không cần khởi tạo lại.

Set-Location D:\project\plan
git remote -v
git status --short
git add -- README.md ke-hoach-phan-bo-7-2-trieu.html docs/goals-prod-deploy-runbook.html
git diff --cached --check
git diff --cached --stat
git commit -m "Document Goals deployment and add application"
git push -u origin main

Bỏ commit nếu không có thay đổi. Trên GitHub phải có file HTML ứng dụng, không chỉ README. Nếu gặp lỗi 403: cấp quyền repo cho tài khoản đang xác thực hoặc đăng nhập tài khoản có quyền rồi push lại. Không đưa token vào URL remote.

3. Kiểm tra VPS

WINDOWS

ssh vps
# Hoặc: ssh deploy@62.171.135.240

SERVER — Bash

whoami
cd /srv/caddy
docker compose ps
docker inspect "$(docker compose ps -q caddy)" --format '{{json .Mounts}}'
docker compose exec caddy cat /etc/caddy/Caddyfile
test -w /srv/apps
test -w /srv/caddy/conf/sites
df -h

User cần là deploy; nếu root thì dùng su - deploy. Kiểm tra mount Source /srv/caddy/conf → Destination /etc/caddy và import sites/*.caddy (hoặc đường dẫn tuyệt đối tương đương). Nếu khác, dừng để điều chỉnh đường dẫn/mount. DNS A/AAAA cần trỏ đúng VPS và cổng 80/443 truy cập được. Không tạo Caddy thứ hai hoặc mở cổng ứng dụng riêng.

4. Deploy lần đầu

4.1. Clone đúng repo

SERVER

cd /srv/apps && git clone --branch main https://github.com/congvu99/Goals.git goals
cd /srv/apps/goals
git remote -v
git log --oneline -1
test -s ke-hoach-phan-bo-7-2-trieu.html

Clone/kiểm tra file lỗi thì dừng. Nếu thư mục đã tồn tại, kiểm tra repo trong đó, không xóa để clone lại. Repo private cần quyền đọc GitHub cho user deploy.

4.2. Chép HTML thành trang chủ

Chỉ chạy khi chưa có index.html; lần sau dùng mục 6. SERVER:

(
  set -eu
  cd /srv/apps/goals
  test -s ke-hoach-phan-bo-7-2-trieu.html
  sudo install -d -o deploy -g deploy -m 755 /srv/caddy/conf/goals-public
  sudo install -d -o deploy -g deploy -m 700 /srv/backups/goals
  test ! -e /srv/caddy/conf/goals-public/index.html
  install -m 644 ke-hoach-phan-bo-7-2-trieu.html /srv/caddy/conf/goals-public/index.html.new
  mv /srv/caddy/conf/goals-public/index.html.new /srv/caddy/conf/goals-public/index.html
  git rev-parse HEAD > /srv/backups/goals/deployed-commit.txt
)

4.3. Thêm site Caddy

SERVER — từ chối ghi đè file site đã có:

(
  set -eu
  set -o noclobber
  cat > /srv/caddy/conf/sites/goals.caddy <<'EOF'
goals.congvu.duckdns.org {
    root * /etc/caddy/goals-public
    encode zstd gzip
    header Cache-Control "no-cache"
    file_server
}
EOF
)
cd /srv/caddy
docker compose exec caddy test -r /etc/caddy/goals-public/index.html
docker compose exec caddy caddy validate --config /etc/caddy/Caddyfile && \
docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile

Nếu site đã có, xem và chỉnh file đó; lưu backup ngoài thư mục sites. Chỉ reload khi validate thành công. Caddy phục vụ index.html tại / và tự quản lý HTTPS khi DNS/cổng đúng.

6. Cập nhật

Push code lên main trước. Chỉ một người chạy deploy/rollback tại một thời điểm. SERVER:

(
  set -eu
  cd /srv/apps/goals
  test -z "$(git status --porcelain)"
  git pull --ff-only origin main
  test -s ke-hoach-phan-bo-7-2-trieu.html
  stamp=$(date -u +%Y%m%dT%H%M%S%N)
  backup="/srv/backups/goals/index-$stamp.html"
  cp /srv/caddy/conf/goals-public/index.html "$backup"
  chmod 600 "$backup"
  cp /srv/backups/goals/deployed-commit.txt "$backup.commit"
  install -m 644 ke-hoach-phan-bo-7-2-trieu.html /srv/caddy/conf/goals-public/index.html.new
  mv /srv/caddy/conf/goals-public/index.html.new /srv/caddy/conf/goals-public/index.html
  git rev-parse HEAD > /srv/backups/goals/deployed-commit.txt
  cat /srv/backups/goals/deployed-commit.txt
)

Đổi tên file trong cùng thư mục tránh phục vụ file đang chép dở. Thay HTML không cần reload Caddy. Chạy lại mục 5; không có cơ chế tự rollback nếu giao diện lỗi. Backup không tự xóa, cần theo dõi dung lượng.

7. Backup và rollback

Không có database server. Giữ source trên GitHub, HTML đã phát hành và cấu hình Caddy. SERVER — chọn bản trước:

ls -lt /srv/backups/goals/index-*.html

Thay đường dẫn mẫu bằng file thực tế. Khối dưới giữ thêm bản hiện tại trước khi khôi phục:

(
  set -eu
  backup=/srv/backups/goals/index-THOI_DIEM.html
  test -s "$backup"
  current="/srv/backups/goals/before-rollback-$(date -u +%Y%m%dT%H%M%S%N).html"
  cp /srv/caddy/conf/goals-public/index.html "$current"
  chmod 600 "$current"
  cp /srv/backups/goals/deployed-commit.txt "$current.commit"
  install -m 644 "$backup" /srv/caddy/conf/goals-public/index.html.new
  mv /srv/caddy/conf/goals-public/index.html.new /srv/caddy/conf/goals-public/index.html
  if [ -f "$backup.commit" ]; then
    cp "$backup.commit" /srv/backups/goals/deployed-commit.txt
  else
    printf 'restored from %s; commit unknown\n' "$backup" > /srv/backups/goals/deployed-commit.txt
  fi
)

Kiểm tra lại mục 5, đối chiếu hash với backup đã chọn. Rollback HTML không đổi HEAD của repo; lần cập nhật sau phát hành code trên main.

WINDOWS — bản sao ngoài VPS:

New-Item -ItemType Directory -Force D:\backup\goals
scp -r vps:/srv/backups/goals D:\backup\goals\
scp vps:/srv/caddy/conf/sites/goals.caddy D:\backup\goals\

Cấu hình và volume TLS của Caddy theo quy trình backup chung của VPS. Bản sao cùng VPS không bảo vệ khi mất cả máy chủ.
